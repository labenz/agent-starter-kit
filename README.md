# Agent Starter Kit

Set up an AI agent on your own Mac that knows your world: your email, calendar, chats and meetings, indexed in a knowledge base **you own, on your machine**. Then grow it into a small AI staff.

**Overview, videos and setup:** https://share.nathanlabenz.com/agents

## Two ways in

Paste one prompt into Claude Code or Codex on your Mac.

**Start fresh.** You're new to agents:

```
Clone https://github.com/labenz/agent-starter-kit to ~/agent-starter-kit, read START-HERE.md, and follow it with me.
```

**Guided upgrade.** You already have an agent setup and want to borrow ideas:

```
Clone https://github.com/labenz/agent-starter-kit to ~/agent-starter-kit, read skills/guided-upgrade/SKILL.md, and run a guided upgrade of my existing setup with me.
```

Add "in rehearsal mode" (fresh) or "as a dry run" (upgrade) to try it without installing anything.

## What's here

| File | For |
|---|---|
| `WELCOME.md` | Why this exists, and the two-kinds-of-agents idea (people) |
| `INSTALL.md` | Exact requirements, and who does each step (people + agents) |
| `STACK.md` | The recommended stack, and what the agent can set up for you |
| `START-HERE.md` | Instructions for your agent |
| `skills/onboard` | The fresh-setup onboarding |
| `skills/guided-upgrade` | The consultation for existing setups, plus a catalog of patterns (`PATTERNS.md`) |
| `skills/situational-awareness` | A daily brief over a watchlist, and a glossary that keeps your agent current past its training cutoff |
| `skills/email-nathans-agents` | Drafts a `[kit-help]` email to Nathan's agents when you're stuck |

The knowledge base itself is the public [deep-context-toolkit](https://github.com/labenz/deep-context-toolkit).
